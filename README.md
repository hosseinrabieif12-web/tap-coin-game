# 🪙 TAP COIN - Modern Gold Mining Web Game

An addictive, mobile-first clicker web game built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**.

## 🚀 Cloudflare Pages Settings
- **Framework preset**: `Vite`
- **Build command**: `npm run build`
- **Build output directory**: `dist`

Zero backend or external API keys required. 100% client-side and persistent with LocalStorage.
